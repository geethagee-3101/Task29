# Task 29 – Basic Conditional Formatting

## Objective
To highlight the top and bottom sales values automatically using Excel conditional formatting.

## Tools Used
- Microsoft Excel

## Dataset
Sample Retail Sales Dataset (50 orders).

## Work Completed
- Applied Top 10 conditional formatting.
- Applied Bottom 10 conditional formatting.
- Added sales data bars.
- Highlighted high and low unit quantities.
- Created a summary sheet and rules list.

## Outcome
Successfully automated Excel formatting to identify the highest and lowest sales values and improve report readability.
